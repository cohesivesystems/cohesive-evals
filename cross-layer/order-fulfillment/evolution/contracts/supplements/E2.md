## Cancellation

Add persistent terminal status `Cancelled` to order summary/details.

| Request | Current status | Response |
|---|---|---|
| POST /orders/{id}/cancel | Draft | 200 summary, now Cancelled |
| same | Cancelled | 200 unchanged summary |
| same | Any other existing status | 409 `{code:"OrderNotCancellable"}`, unchanged |
| same | Unknown order | 404 |

No request body is required or read; an optional body is ignored. Cancellation
changes only order status. Inventory, reservations and unrelated orders remain
unchanged. Cancelled cannot be submitted or reopened.

Direct submit of Cancelled returns 409 `{code:"OrderCancelled"}`. Fulfillment
returns HTTP 200 `{status:"Rejected",outcome:"OrderCancelled"}` at the lifecycle
decision, after all existing inventory rules; other non-Draft states retain their
specified outcomes. Completed rejection has no new reservation or net stock
change. Completed-request replay remains unchanged after cancellation.
